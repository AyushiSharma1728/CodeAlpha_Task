# CodeAlpha Data Science Internship

This repository contains my projects completed during the **CodeAlpha Data Science Internship** using Python and Machine Learning.

##  Tasks

### Task 1 – Iris Flower Classification

Classified Iris flowers into different species using Machine Learning.

**Libraries:** Pandas, NumPy, Scikit-learn, Matplotlib, Seaborn

### Task 2 – Unemployment Analysis

Analyzed unemployment trends, regional differences, and the impact of COVID-19 using data visualization.

**Libraries:** Pandas, NumPy, Matplotlib, Seaborn

### Task 3 – Car Price Prediction

Built a Machine Learning model to predict car prices based on different features.

**Libraries:** Pandas, NumPy, Scikit-learn, Matplotlib
